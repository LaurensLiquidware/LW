# Screenshots

Drop screenshot images here (e.g. via GitHub's "Add file" → "Upload files"
right in this folder) and reference them from the main `README.md`'s
Screenshots section.

Suggested filenames, matching what's described there:

- `active-download.png` — the flyout panel with a download in progress
- `diagnostics.png` — the tray menu's Diagnostics dialog
- `history.png` — the flyout panel's History section

If you use different filenames, update the links in `../README.md` to match.

**Before uploading a Diagnostics screenshot**: crop or block out the
`Last raw token event:` line if it's visible — it contains a local
Windows security identifier (SID) specific to the machine it was
captured on. Not a secret, but no reason to publish it either.
